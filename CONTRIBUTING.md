# Contributing to Automation Templates

Contributions are welcome! Please follow these guidelines:

## How to Contribute
1.  Fork this repository.
2.  Create a new branch for your workflow.
3.  Add your n8n workflow JSON file to the `workflows/` directory.
4.  Update `README.md` to include your new workflow in the catalog with a brief description.
5.  Submit a pull request.

Please ensure your workflow JSON does not contain any hardcoded sensitive credentials (API keys, passwords, etc.). Use environment variables where possible.
